# Моделирование дискретных сигналов

Проект реализует имитационное моделирование одномерного дискретного детерминированного сигнала в тригонометрическом базисе. Программа сравнивает экспериментальную автокорреляционную функцию с теоретическим аналогом, рассчитывает абсолютную погрешность и отображает интерактивные графики.

## Требования к моделям сигналов

Интерфейс поддерживает два режима работы без перезапуска сервера:

1. **Дискретный белый шум**
   * Спектральная плотность мощности постоянна в полосе частот.
   * Теоретическая автокорреляционная функция рассчитывается через отношение синуса аргумента к самому аргументу. При нулевом сдвиге программа раскрывает неопределенность, приравнивая значение к дисперсии.

2. **Сигнал с экспоненциальной спектральной плотностью мощности**
   * Спектральная плотность мощности имеет спад по экспоненциальному закону.
   * Граничная частота вычисляется на основе коэффициента дискретизации.
   * Теоретическая автокорреляционная функция рассчитывается по экспоненциальному закону.

## Физический смысл параметров

* **Вариант сигнала** определяет форму спектральной плотности мощности.
* **Число отсчетов** задает размер выборки сигнала. Рост числа отсчетов повышает точность расчета экспериментальной автокорреляционной функции и приближает ее к теоретической форме.
* **Частота среза** определяет ширину спектра сигнала. Высокая частота среза сжимает автокорреляционную функцию во времени, делая ее график более узким.
* **Параметр дискретизации** задает интервал времени между отсчетами. Малые значения параметра уменьшают шаг дискретизации, что повышает точность воспроизведения формы сигнала.
* **Дисперсия** задает мощность сигнала. Данный параметр масштабирует амплитуду сигнала и пиковое значение автокорреляционной функции при нулевом сдвиге.

## Инструкция по запуску

Для подготовки среды и запуска выполните команду:
```bash
./configure.sh
```

Скрипт проверяет наличие виртуального окружения и создает его при отсутствии. Установка зависимостей происходит через быстрый установщик пакетов. Повторный запуск скрипта считывает контрольную сумму требований и пропускает этап сетевой загрузки библиотек.
